# API CRUD com Node.js e Express

## 📌 Sobre o projeto

Este projeto consiste na criação de uma API REST utilizando **Node.js** e **Express**, com o objetivo de praticar a construção de servidores, criação de rotas HTTP e organização de uma aplicação backend.

O projeto foi desenvolvido como parte dos estudos em desenvolvimento backend, explorando conceitos fundamentais de APIs e requisições HTTP.

---

## 🚀 Tecnologias utilizadas

* Node.js
* Express.js
* JavaScript
* npm

---

## ⚙️ Instalação e execução

### 1. Clone o repositório

```bash
git clone https://github.com/LuciieneSantos/NOME-DO-REPOSITORIO.git
```

### 2. Acesse a pasta do projeto

```bash
cd projeto-nodejs
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o servidor

```bash
node index.js
```

O servidor será iniciado na porta configurada no projeto.

---

## 🌐 Rotas disponíveis

### Página inicial

**GET /**

Retorna uma mensagem de boas-vindas da API.

---

### Login

**POST /login**

Simula o recebimento de uma requisição de login.

---

### Atualização de usuário

**PUT /user/:id**

Recebe o identificador de um usuário para simular uma atualização.

Exemplo:

```bash
/user/1
```
